# Electricity Theft Detection Using Machine Learning

A university machine-learning project that detects potentially fraudulent
electricity consumers from historical smart-meter consumption data, using
engineered consumption features and three conventional ML models: Logistic
Regression, Random Forest, and XGBoost.

## Problem Statement

Research question: *Can engineered consumption-pattern features reliably
distinguish electricity theft from normal usage, and which conventional ML
model performs best under severe class imbalance?*

Task: binary classification — `0` = normal consumer, `1` = theft consumer —
producing a theft probability / risk score per customer. **Predictions are
indicators for investigation, not proof of electricity theft.**

## Dataset

[SGCC Electricity Theft Detection Dataset](https://github.com/henryRDlab/ElectricityTheftDetection)
(Zheng et al., *Wide and Deep Convolutional Neural Networks for
Electricity-Theft Detection to Secure Smart Grids*, IEEE TII 2018).
42,372 consumers, daily readings from 2014-01-01 to 2016-10-31, 3,615 theft
cases (8.5%). See [`data/raw/DATA_SOURCE.md`](data/raw/DATA_SOURCE.md) for
the exact download source, citation, and a SHA-256 checksum of the verified
file used in this project.

## Technology Stack

Python 3.14, scikit-learn, XGBoost, pandas/NumPy, Streamlit + Plotly
(dashboard), Matplotlib/Seaborn (report figures), pytest.

## Architecture

```
data/raw (SGCC CSV) -> src/data (load/validate/clean/impute/split/features)
  -> src/models + src/training (Logistic Regression, Random Forest, XGBoost)
  -> src/evaluation (metrics, comparison, plots)
  -> artifacts/ (models, metrics, figures)
  -> app/ (Streamlit dashboard reading only saved artifacts)
```

See [`METHODOLOGY.md`](METHODOLOGY.md) for the full methodology, and
[`RESULTS.md`](RESULTS.md) for the actual evaluation numbers (generated by
`scripts/run_evaluation.py` from real experiment outputs — never
hand-written).

## Installation

```bash
python3.14 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

(If XGBoost fails to import on macOS, install the OpenMP runtime it needs:
`brew install libomp`.)

## Dataset Placement

The verified CSV is already at `data/raw/sgcc_data.csv` (see
`data/raw/DATA_SOURCE.md`). To re-download from the original source:

```bash
curl -L -o data.zip https://raw.githubusercontent.com/henryRDlab/ElectricityTheftDetection/master/data.zip
curl -L -o data.z01 https://raw.githubusercontent.com/henryRDlab/ElectricityTheftDetection/master/data.z01
curl -L -o data.z02 https://raw.githubusercontent.com/henryRDlab/ElectricityTheftDetection/master/data.z02
7zz x data.zip -oextracted/   # 7-Zip handles this multi-volume zip correctly;
                              # macOS's built-in `unzip`/`zip -FF` does not.
cp extracted/data.csv data/raw/sgcc_data.csv
```

## Running the Project

```bash
# 1. Prepare data (QUICK MODE: small stratified subset, fast; or full dataset)
python scripts/prepare_data.py --quick
python scripts/prepare_data.py            # full dataset (~10s on a laptop)

# 2. Train baselines (Logistic Regression, Random Forest, XGBoost)
python scripts/run_training.py            # full dataset
python scripts/run_training.py --quick    # quick mode

# 3. Aggregate results, generate figures, write RESULTS.md
python scripts/run_evaluation.py

# 4. Launch the dashboard
streamlit run app/main.py

# 5. Run tests
pytest tests/ -v

# 6. Full pipeline smoke test on a tiny synthetic fixture (fast, CI-friendly)
python scripts/smoke_test.py
```

Individual training command:

```bash
python src/training/train_baselines.py
```

## QUICK MODE vs. FULL MODE

- **QUICK MODE** (`--quick`): a stratified ~4,000-customer subset, for fast
  iteration/demo. Results from this mode are never presented as full-dataset
  results — the dashboard displays a "QUICK MODE" badge whenever this data
  is in use.
- **FULL MODE** (default): the complete, cleaned ~42,285-customer dataset.

## Troubleshooting

- **"No processed dataset found" in the dashboard**: run `scripts/prepare_data.py` first.
- **XGBoost import error on macOS**: `brew install libomp`.
- **Multi-volume zip extraction fails with `unzip`/`zip -FF`**: use 7-Zip (`brew install sevenzip`; see Dataset Placement above) — the standard macOS zip tools cannot correctly join this archive's three parts.
